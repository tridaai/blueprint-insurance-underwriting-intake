How it works

extract → ingest (computed facts) → injection screen → triage (rules + LLM cross-check) → guideline retrieval → diagnosis (bounded tool loop) → scored options → draft letter + packet → self-verify → independent review → guardrails → underwriter gate. Code computes the numbers; the model does language work; the human decides.

Approval records the decision. Nothing is emailed, quoted, or bound by the agent; with ACTION_WEBHOOK_URL configured, the approved packet is routed to that endpoint instead.
